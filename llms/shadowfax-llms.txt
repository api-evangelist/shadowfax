## What the product does

Shadowfax AI combines a spreadsheet, a BI tool, a visual pipeline and a code
notebook into one analyst-in-the-loop workflow. Users upload data files, which are
held immutable as Sources; every transformation produces a new View, so each
result traces back to its origin with inspectable SQL and a full lineage graph.
The stated goal is analysis that is defensible, auditable and reproducible enough
for executive review.

- Supported source formats: CSV, TSV, Excel (.xlsx), Parquet
- Live database connections (Snowflake, BigQuery and others): announced as coming soon
- Key features: Workbooks, Sources, Views, AI Tables, AI Chat Interface, Node Graph,
  Schema Discovery, Reactive System, Manual SQL Mode, Slash Commands,
  @Mentions and References, Input Objects, Quick AI Editing, Data Refresh
- Visualization: Vega-spec based; exports to CSV, SQL, JSON (Vega), PNG, SVG

## Plans

- Free — $0/month, available now during public beta. All core features, standard
  usage limits, basic data sources, standard rate limits. No credit card required.
- Pro — $20/month, coming soon. More usage, advanced data sources, priority email
  support, higher rate limits.
- Enterprise — custom pricing, contact sales. Custom usage limits, dedicated
  support, advanced security and compliance, SSO/SAML, data residency and
  regional deployment.

Commercial pricing after beta is stated as moving to a token-credit consumption
model; the structure is still TBD. AI agent conversations, AI Table processing,
query planning and visualization generation consume credits; viewing Views,
running SQL on Views, exporting and collaboration do not.

## Rate limits

No numeric rate limit is published anywhere on the public surface. The docs
describe limits only qualitatively ("generous", "fair usage", "99% of users will
never hit them") and say a user approaching a limit will be contacted directly.
